# Personal Portfolio Website

A responsive personal portfolio website built using **HTML and CSS** to showcase my skills, projects, experience, and achievements.

## Features

* Clean and simple user interface
* Responsive design for different screen sizes
* About Me section
* Skills section
* Projects section
* Contact section
* Navigation between different sections

## Technologies Used

* **HTML5** – Structure and content of the website
* **CSS3** – Styling, layout, responsiveness, and visual design

## Purpose

This project was created to build and showcase my personal portfolio while strengthening my fundamentals in **HTML and CSS**.
